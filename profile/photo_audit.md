# Photo audit notes (example template)

> Generic template. The image files are not stored in this repo (`.gitignore` blocks images in `profile/`). Replace the bullets with your own findings.

Checked against the profile-optimizer photo criteria: at least 400x400, face about 60% of the frame, under 3 years old, natural light, slight smile.

## Checklist

| Criterion | Result | Note |
|---|---|---|
| Resolution | Pass / fail | 800x800 is twice the minimum |
| Framing | Pass / fail | Head and shoulders, about 60% of the frame, room above the hair for the circular crop |
| Expression | Pass / fail | The criteria ask for a slight smile |
| Background | Pass / fail | Plain, light, contrasts with the banner; look for compression blotches |
| Age | Pass / fail | Under 3 years old, not heavily retouched |

## Typical fixes

- **Background blotches** (repeated saves or app filters): upload the original, or smooth only the background pixels away from the outline and keep a faint grain.
- **Expression:** retake with a small closed-mouth smile. A local warp of the mouth corners is barely visible at thumbnail size and looks fake if pushed; a believable smile also changes the cheeks and eyes.
- **Generative edits** upload the face to an outside service. Do that only with explicit approval and check the result still looks like the person.

## Banner

One image, text in the middle third so the mobile crop keeps it. Example: line 1 "Leading engineers · API integrations", line 2 "Senior Backend Engineer · Python · AWS".
